# BeBetterHunter

Catalogue hors ligne des capacités de familiers pour WoW Forever (interface 16001).

- `/bbh` ou `/bebetterhunter` ouvre la fenêtre.
- **Capacités** : choisir une capacité et un rang pour voir le niveau requis, le coût connu et les bêtes qui enseignent ce rang. Cliquer sur une bête pour afficher ses points d'apparition.
- **Familiers rares** : rechercher un nom ou une zone, puis voir la zone, le niveau et les halos des points d'apparition connus.

Les données couvrent 36 capacités et 80 bêtes rares, d'après le [catalogue WoW Forever de Mmonster](https://mmonster.co/wow-forever/guides/hunter-pets/abilities), vérifié pour la bêta 1.60.1.70450. Les capacités récentes ou particulières dont l'apprentissage n'est pas documenté affichent une liste de bêtes vide. Les noms de capacités, de bêtes et de zones proviennent de cette source en anglais.

Les coordonnées de carte viennent de Questie quand il est installé et chargé. Sans Questie, les listes, niveaux et zones restent consultables. Les halos marquent les points connus, sans indiquer qu'un rare est actuellement présent. L'affichage de carte et la texture de halo reprennent l'approche de GatherTogether.
